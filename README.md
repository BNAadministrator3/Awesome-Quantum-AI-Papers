## Contribution Guidelines

- **Physical Devices and Control Systems:** Experimental QEC, logical-qubit demonstrations, real-time feedback, controller benchmarks, and quantum processor integration.
- **Algorithms and QEC Theory:** Decoder algorithms, machine learning, code construction, error thresholds, and fault-tolerant protocols.
- **Hardware Implementations and Accelerators:** FPGA/ASIC decoders, dedicated chips, hardware–algorithm co-design, and cryogenic control electronics.

Each paper should appear in one primary category to avoid duplicate entries. Related work outside direct QEC should be clearly identified.
